Wakes.

A visionOS tower-defense game built for Apple Vision Pro, where the player isn't building towers — they are the defense, using hand-tracked throws and gestures to fend off waves of enemies in mixed reality.

About the project

What is Wakes?

Wakes reimagines the genre for spatial computing. Instead of placing static towers on a map, the player stands at their own base and defends it directly: throwing darts at enemies marching in from a fixed path, all tracked through the Vision Pro's native hand tracking.

The core loop follows a classic wave structure: survive a wave, earn money from defeated enemies, then spend it in the shop before the next wave hits. Enemies range from standard grunts to fast, low-health Runners and slow, high-health Tanks, each demanding a different response. Under the hood, the game is built with RealityKit's Entity-Component-System architecture, SwiftUI for the overlay UI, and fully manual physics for weapon arcs and projectiles.
